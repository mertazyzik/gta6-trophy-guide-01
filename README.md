**Leonida Trophy Atlas** — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in the author's own words with its sources cited beside it, a three-stage roadmap to the platinum (~200 hours), a flag on the one trophy that may be missable, and a checklist that saves in the browser, exports to a file and imports back. Filters by kind (story, missable, collectibles, activities, side quests, online) and a spoiler setting that hides story trophies until earned. No network at runtime, no Rockstar artwork — a look of its own.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or build the submission output with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
